# MoeCopilot

Outil de génération de CCTP et d'estimatifs pour les projets paysage et espaces verts, à partir d'un formulaire de saisie guidée.

---

## À quoi ça sert

La rédaction d'un CCTP et de son estimatif associé est une tâche longue et répétitive en bureau d'études. MoeCopilot permet de :

- Renseigner les caractéristiques d'un projet via un formulaire structuré
- Générer automatiquement les pièces écrites du marché (CCTP)
- Produire un estimatif cohérent avec les prestations décrites
- Adapter les documents aux spécificités du projet (type d'espace, contexte urbain, contraintes site)
